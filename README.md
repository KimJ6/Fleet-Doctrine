# Fleet Doctrine

3차원 우주 전장에서 함대를 편성하고 이동 명령을 내린 뒤 자동 전투를 관찰하는 컴퓨터그래픽스 프로젝트입니다. 현재 웹 프로토타입에서 함대 이동과 시험 전투를 실행할 수 있습니다.

## 게임 실행

Python 3.12와 브라우저가 필요합니다. three.js 등 라이브러리를 CDN에서 불러오므로 인터넷 연결이 필요합니다. 저장소와 별도 함선 에셋은 다음과 같이 같은 상위 폴더에 있어야 합니다.

```text
텀프3/
├─ Fleet Doctrine/                 # 이 저장소
└─ ship assets/rigged/
   ├─ Light_cruiser_01_rigged.fbx
   └─ Texture/
```

PowerShell에서 **저장소의 상위 폴더**를 연 뒤 다음 명령을 실행하고 창을 열어 둡니다. `uv`가 설치되어 있어야 하며, 해당 포트에서 이미 올바른 서버가 실행 중이면 다시 실행할 필요가 없습니다.

```powershell
uv run --no-project --python 3.12 python -m http.server 8001 --bind 127.0.0.1
```

- [게임 프로토타입 열기](http://127.0.0.1:8001/Fleet%20Doctrine/web/)
- [함선 리깅 테스트 열기](http://127.0.0.1:8001/Fleet%20Doctrine/rigging-test/)

페이지가 열리지 않거나 모델이 나오지 않으면 서버가 실행 중인지, 서버의 작업 폴더가 위의 `텀프3`처럼 저장소와 `ship assets`를 모두 포함하는지 확인합니다. 다른 프로그램이 8001 포트를 사용한다면 빈 포트로 바꾸고 주소의 포트도 함께 바꿉니다. 연결이 거부되면 서버가 종료된 상태이므로 위 명령을 다시 실행합니다. 게임은 제공된 FBX의 리깅 분석 해시가 일치하지 않으면 안전을 위해 사격을 보류합니다.

## 조작 방법

1. 하단의 함대 탭, 전장 함선 또는 미니맵에서 아군 함대를 선택합니다. 함대 탭의 +로 새 빈 함대를 만들고 함선을 옮길 수 있습니다. 마지막 함선을 다른 함대로 옮기면 기존 빈 함대는 자동 삭제됩니다. 높이별 함선 카드를 서로 드래그하거나 두 카드를 차례로 클릭하면 슬롯을 교환합니다. 함선 카드를 다른 함대 탭으로 드래그하거나 선택한 뒤 탭을 클릭하면 함대를 옮깁니다.
2. **목적지 이동**에서 **목적지 지정**을 누르거나 **경로 순찰**을 선택해 경유점을 추가합니다. XZ 화면에서 수평 위치를, YZ 화면에서 높이를 클릭합니다. 순찰은 서로 다른 경유점 두 개 이상을 지정하고 저장해야 적용되며 카드를 드래그하거나 차례로 클릭해 순서를 바꿀 수 있습니다. 입력 중 WASD와 왼쪽 드래그로 화면을 이동하고, 휠로 확대·축소하며 Esc로 취소할 수 있습니다.
3. 필요하면 하단의 간격 메뉴에서 좁게·보통·넓게 버튼으로 함선 간격을 정하고, **구매·예비** 메뉴에서 점수로 함선을 구매해 선택 함대 또는 신규 함대에 클릭으로 배정하거나 예비 카드를 기존 함대 탭에 드래그합니다. **전투 시작**을 누르면 배정된 함선은 시작 면에 투입됩니다. 전투는 임시로 최대 30초간 진행되며 **준비 단계로** 버튼으로 일시 정지할 수 있습니다.
4. 메인 카메라는 WASD로 전후좌우, R/F로 상하 이동하고 드래그·휠로 회전·확대합니다. XY/YZ/XZ 버튼은 선택 함대 방향으로 시점을 옮깁니다. 미니맵의 평면 선택은 메인 카메라와 독립적입니다. 오른쪽 위에는 개발 확인용 카메라 거리 또는 목적지 입력 줌이 표시됩니다. 함선 구매·예비 메뉴는 전투 시작 버튼 위에 있습니다.

## 현재 구현 상태

- 기본 편성은 아군 8척과 적군 8척이며, 3차원 이동·대형 유지와 함선 근접 완화가 동작합니다. 근접 완화는 완전한 무충돌을 보장하지 않습니다.
- 양측 함선이 표적을 선택하고 포탑·포신을 움직여 자동 사격합니다. 함대 단위로 표적 후보를 공유하고 공간 셀로 주변 함선과 사선 후보를 찾습니다.
- 시험 전투는 포구 레이의 최초 접촉을 **발사 틱에 즉시 판정**합니다. 자기 함선·아군이 앞을 가로막으면 발사를 보류하며, 구형 근사 피격 범위와 짧은 선형 효과를 사용합니다. 탄이 비행하는 동안 차폐가 바뀌는 상황은 아직 반영하지 않습니다.
- 생존 함선으로 9개 구역을 집계하며 현재 점수로 함선을 구매하거나 목표 점수를 모을 수 있습니다. 기본 적 AI도 같은 가격으로 구매하고 시작 면에 투입합니다. 구매 가격과 AI 정책은 시험값입니다. 플레이어 함대는 목적지 이동·순찰과 명령 유지 사격·거리 유지 교전·거점 방어를 선택할 수 있습니다. 거점 방어는 적 조우 시 발동합니다. 5단계 전술은 시제품이며 대표 통합 검증을 마쳤습니다. 진형 관통과 분할 포위는 아직 구현되지 않았습니다.
- 포탑 회전 간섭은 AABB 근사, 자기 함선 포구 안전은 메시 검사를 사용합니다. 피격 형상의 오차와 모델별 회전·사선은 추가 시각 검수가 필요합니다. 이동·무장·득점 수치는 시험용입니다.

전투 기반은 [2단계 상세 재설계](docs/design/phase2-data-oriented-combat-design.md)를 따르며, 순찰과 전술의 구현·검증 현황은 [구현 계획](docs/design/implementation-plan.md)에 정리되어 있습니다. 교전 성능 측정과 비교 한계는 [이슈 #1 조사 기록](docs/investigations/issue-001-combat-performance.md)을 참고합니다.

## 함선 리깅 테스트

리깅 테스트는 게임과 별도로 FBX의 포탑·포신 회전, 포구와 엔진 기준점을 살펴보는 도구입니다. 기본 모델을 불러오거나 테스트 화면에서 FBX와 텍스처를 직접 선택할 수 있습니다. 무장 선택과 회전 축·범위 설정은 테스트 화면에서 조작하며, 설정 변경은 페이지를 유지하는 동안만 유효합니다. 리깅되지 않은 모델에는 무장 조작 항목이 없을 수 있습니다.

이름 규칙, 각도 제어, 검증 절차는 [함선 리깅 정책](docs/policies/ship-rigging.md)과 [리깅 테스트 안내](rigging-test/README.md)를 따릅니다.

### 함선 모델과 라이선스

현재 사용 중인 함선은 CraftPix의 무료 에셋 [Battle SpaceShip Free 3D Low Poly Models](https://craftpix.net/freebies/battle-spaceship-free-3d-low-poly-models/)입니다. 무료 다운로드 에셋이지만 자유 재배포를 허용하는 공개 라이선스나 CC0로 간주하지 않으며, [CraftPix 파일 라이선스](https://craftpix.net/file-licenses/)의 무료 에셋 조건을 따릅니다. 원본에 포함된 `License.txt`도 해당 라이선스 페이지를 안내합니다.

**저장소에는 이 함선 에셋의 원본과 이를 수정한 리깅 파일을 올리지 않습니다.** 프로젝트에서 사용하는 리깅본은 CraftPix 원본을 바탕으로 별도로 수정한 작업 파일입니다. CraftPix에서 원본을 내려받는 것만으로는 이 프로젝트의 포탑·포신 리깅과 기준점을 얻을 수 없습니다. CraftPix는 무료 에셋의 프로젝트 사용과 수정을 허용하지만, 다른 사람이 에셋 자체를 사용할 수 있도록 원본이나 수정본을 재배포하는 데 제한을 둡니다. 이 저장소의 비공개 방침은 이를 고려한 프로젝트 운영 방침이며, 게임 완성물의 모든 배포가 금지된다는 뜻은 아닙니다.

현재 함선 원본 및 리깅 파일은 저장소 밖 상위 폴더의 `ship assets/`에 있습니다. GitHub에서 저장소만 내려받으면 이 프로젝트의 리깅 모델이 포함되지 않으므로 기본 모델을 이용한 게임 및 리깅 테스트를 바로 실행할 수 없습니다. [ASSETS.md](ASSETS.md)는 스타터 팩 에셋 목록이며 CraftPix 함선에 적용되는 라이선스 목록이 아닙니다.
